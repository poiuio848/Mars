# Mars Colony Manager

Projekt wykonany w wersji podstawowej na ocenę dobrą.

## Technologie
- HTML5
- CSS3
- Bootstrap 5
- TypeScript
- jQuery
- LocalStorage

## Funkcje
- tworzenie kolonii,
- dashboard zasobów,
- budynki,
- rozbudowa budynków,
- przechodzenie do następnego dnia,
- zużycie i produkcja zasobów,
- losowe wydarzenia,
- log wydarzeń,
- zapis i wczytanie gry,
- warunki zwycięstwa i przegranej.

## Uruchomienie

1. Zainstaluj Node.js oraz TypeScript.
2. W terminalu przejdź do folderu projektu.
3. Wykonaj:
   `tsc`
4. Skopiuj `dist/app.js` do głównego folderu projektu jako `app.js`
   (albo zmień ścieżkę skryptu w index.html na `dist/app.js`).
5. Otwórz `index.html` w przeglądarce.

Alternatywnie można użyć rozszerzenia Live Server w VS Code.

## Uwaga
Projekt celowo nie zawiera systemu badań, wykresów ani dodatkowych funkcji z poziomu celującego.
